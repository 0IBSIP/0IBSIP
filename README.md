📂 Projects

1. Retail Sales Exploratory Data Analysis (EDA)

In this project, I explored retail sales data to understand what information it contains and what useful patterns can be found through analysis.

I worked on inspecting the dataset, checking data quality, exploring different variables, and creating visualizations to make the results easier to understand.

What I worked on:

- Exploring and understanding the dataset
- Checking missing values, duplicates, and data types
- Performing exploratory data analysis
- Creating charts and visualizations
- Identifying useful findings and possible business improvements

Tools used: Python, Pandas, NumPy, Matplotlib, Seaborn

Notebook: "Task_1_Retail_Sales_EDA.ipynb"

2. Customer Segmentation Using K-Means

This project focuses on understanding customer purchasing behavior and exploring how customers can be grouped based on similarities in their data.

I worked with retail transaction data and explored customer-level analysis and clustering techniques. The goal was to understand how businesses can use customer data to identify different purchasing patterns.

What I worked on:

- Preparing and exploring customer transaction data
- Calculating customer-related metrics where applicable
- Exploring RFM analysis, if included in the notebook
- Applying K-Means clustering
- Visualizing and interpreting customer groups

Tools used: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

Notebook: "Task_2_Customer_Segmentation.ipynb"

3. Titanic Data Cleaning and Preprocessing

For this project, I worked on preparing the Titanic dataset for further analysis. It helped me understand why data cleaning is an important part of any data analytics workflow.

Before analyzing data, we need to check whether it is complete, consistent, and in a suitable format. This project focuses on identifying data quality issues and applying appropriate preprocessing steps.

What I worked on:

- Loading and exploring the dataset
- Checking missing values and duplicate records
- Understanding numerical and categorical columns
- Applying suitable data cleaning techniques
- Preparing and validating the data for further analysis

Tools used: Python, Pandas, NumPy, Matplotlib, Seaborn

Notebook: "Task_3_Titanic_Data_Preprocessing.ipynb"
